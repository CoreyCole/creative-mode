# Plan: HTTP Hardening — Body Limits, Security Headers, Admin-Gate Swarm, Auth Logging (v1)

## Goal

Harden the harness HTTP layer by adding request body size limits, standard security headers, admin-only gating on swarm dashboard mutation actions, and auth failure logging with source IPs. All changes are confined to 3 files in `harness/internal/server/`.

## Acceptance Criteria

- [ ] All HTTP responses include security headers (X-Frame-Options, X-Content-Type-Options, X-XSS-Protection, HSTS, Referrer-Policy)
- [ ] Request bodies are limited to 10 MB globally
- [ ] HSTS is skipped when `DEV_MODE=true`
- [ ] X-Frame-Options uses SAMEORIGIN (not DENY) so game iframes work
- [ ] Swarm dashboard POST routes (cancel/approve/reject) require admin role
- [ ] Swarm dashboard GET routes remain accessible to all approved users
- [ ] All three auth middlewares (hook secret, president, mayor) log failures with source IP
- [ ] `hookSecretMiddleware` accepts a `*slog.Logger` parameter (3 call sites updated)
- [ ] `presidentAuthMiddleware` accepts a `*slog.Logger` parameter (1 call site updated)

## Implementation Steps

### Step 1: Add BodyLimit and SecureWithConfig middleware (server.go)

Insert two new middleware registrations right after `middleware.Recover()` (line 123), before any route registration:

```go
e.Use(middleware.BodyLimit("10M"))
```

For security headers, use conditional config to skip HSTS in dev mode:

```go
hstsMaxAge := 31536000 // 1 year
if os.Getenv("DEV_MODE") == "true" {
    hstsMaxAge = 0
}
e.Use(middleware.SecureWithConfig(middleware.SecureConfig{
    XSSProtection:      "1; mode=block",
    ContentTypeNosniff: "nosniff",
    XFrameOptions:      "SAMEORIGIN",
    HSTSMaxAge:         hstsMaxAge,
    ReferrerPolicy:     "strict-origin-when-cross-origin",
}))
```

Key decisions:
- **SAMEORIGIN** (not DENY) — DENY breaks game iframes loaded via `/world/:worldID/:cpID/trunk/*` and `/wasm/:worldID/:cpID/*`
- **HSTS max-age 0 in dev** — prevents sticky HTTPS redirects during local development
- **No CSP** — game iframes, Datastar, and inline handlers make CSP complex; deferred

### Step 2: Update hookSecretMiddleware to accept logger (server.go)

Change the function signature from `hookSecretMiddleware()` to `hookSecretMiddleware(logger *slog.Logger)` and add auth failure logging:

```go
func hookSecretMiddleware(logger *slog.Logger) echo.MiddlewareFunc {
    secret := os.Getenv(swarm.EnvKey("HookSecret"))
    return func(next echo.HandlerFunc) echo.HandlerFunc {
        return func(c echo.Context) error {
            if secret != "" && c.Request().Header.Get("X-Hook-Secret") != secret {
                logger.Warn("hook secret auth failed",
                    "ip", c.RealIP(),
                    "path", c.Path(),
                )
                return echo.NewHTTPError(http.StatusForbidden, "invalid hook secret")
            }
            return next(c)
        }
    }
}
```

### Step 4: Update presidentAuthMiddleware to accept logger (president_api.go)

Change the function signature from `presidentAuthMiddleware()` to `presidentAuthMiddleware(logger *slog.Logger)` and add auth failure logging. Add `"log/slog"` to imports:

```go
func presidentAuthMiddleware(logger *slog.Logger) echo.MiddlewareFunc {
    secret := os.Getenv("PRESIDENT_SECRET")
    return func(next echo.HandlerFunc) echo.HandlerFunc {
        return func(c echo.Context) error {
            if secret == "" {
                return echo.NewHTTPError(
                    http.StatusServiceUnavailable,
                    "president not configured",
                )
            }
            if c.Request().Header.Get("X-President-Secret") != secret {
                logger.Warn("president auth failed",
                    "ip", c.RealIP(),
                    "path", c.Path(),
                )
                return echo.NewHTTPError(http.StatusForbidden, "invalid president secret")
            }
            return next(c)
        }
    }
}
```

`mayorAuthMiddleware` is already a method on `Server`, so it has `s.Logger`. Add logging at the two failure points:

```go
func (s *Server) mayorAuthMiddleware(next echo.HandlerFunc) echo.HandlerFunc {
    return func(c echo.Context) error {
        secret := c.Request().Header.Get("X-Mayor-Secret")
        if secret == "" {
            s.Logger.Warn("mayor auth failed: missing secret",
                "ip", c.RealIP(),
            )
            return echo.NewHTTPError(http.StatusUnauthorized, "missing mayor secret")
        }

        w, err := s.DB.GetWorldByMayorSecret(c.Request().Context(), sql.NullString{
            String: secret,
            Valid:  true,
        })
        if err != nil {
            s.Logger.Warn("mayor auth failed: invalid secret",
                "ip", c.RealIP(),
            )
            return echo.NewHTTPError(http.StatusForbidden, "invalid mayor secret")
        }

        c.Set("mayor_world", &w)
        return next(c)
    }
}
```

## Risks

- **X-Frame-Options SAMEORIGIN vs DENY**: The parent ticket plan specified DENY, but DENY breaks same-origin game iframes. SAMEORIGIN is the correct choice per research.
- **HSTS in dev**: Setting `HSTSMaxAge: 0` when `DEV_MODE=true` effectively disables HSTS, preventing sticky HTTPS redirects on local/dev setups.
- **Non-admin users see buttons that 403**: After admin-gating, the dashboard UI still shows approve/reject/cancel buttons to non-admin approved users. Clicking them returns 403. This is a frontend concern beyond this ticket's scope — the backend security gate is the priority.
- **Echo route overlap**: Both `approved` (GET) and `swarmAdmin` (POST) groups register paths under `/swarm/:id/...`. Echo matches by method + path, so there's no conflict — GET goes to `approved`, POST goes to `swarmAdmin`.
