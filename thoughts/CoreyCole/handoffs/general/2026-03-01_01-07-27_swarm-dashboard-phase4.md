## Learnings

- **Swarm enum names differ from intuitive names**: `swarm.StatusComplete` (not `StatusCompleted`), `swarm.MilestoneStatusPassed`/`MilestoneStatusFailed` (not `MilestonePassed`/`MilestoneFailed`). See `harness/internal/swarm/enums.go`.
- **Swarm events are published globally** via `EventBus.PublishGlobal()` from `swarmorch/manager.go`, not per-world. The SSE handler uses `SubscribeGlobal()` and filters for `strings.HasPrefix(eventType, "swarm.")`.
- **EventBus event payloads** are `map[string]any` with an `"event"` key containing the event type string (e.g. `events.EventSwarmWorkflowStarted = "swarm.workflow_started"`).
- **`ListSwarmEventsByWorkflow`** takes `sql.NullString` (not a plain string) because the `workflow_id` column in `swarm_events` is nullable.
- **golangci-lint enforces**: `errors.Is()` instead of `==` for error comparison, named constants instead of magic numbers.
- **Playwright on ARM64 Linux**: `npx playwright install chrome` fails ("not supported on Linux Arm64"). `npx playwright install chromium` succeeds but `playwright-cli` still looks for `chrome` channel at `/opt/google/chrome/chrome`. The `PLAYWRIGHT_MCP_BROWSER=chromium` env var may fix this but was not tested.

## Other Notes

- The dashboard SSE handler includes a 30s heartbeat ticker (unlike the mayor dashboard which has none). This follows the `handleWorldSSE` pattern in `events.go` for better connection health.
- The cancel handler (`POST /swarm/:id/cancel`) returns an SSE patch of the full `WorkflowPage` — this works with Datastar's `PostSSE` action from the cancel button.
- Route order matters: `/swarm/events` is registered before `/swarm/:id` to prevent the `:id` param from matching "events". See `server.go:196-199`.
- The `site (golangci-lint)` step in `just check` also shows `FAIL` in the error output but this is a pre-existing issue unrelated to our changes — the harness lint passes cleanly.
