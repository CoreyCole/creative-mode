## Learnings

- **`playwright-cli install`** generates the SKILL.md and references; `install-browser` is not a standalone setup command — it requires an open browser.
- **Config file not auto-loaded** — The `playwright-cli.json` config at project root is not automatically picked up. Screenshots save to `.playwright-cli/` in the project directory by default (which is fine — we gitignore it).
- **`--headed` flag** is needed to see the browser window, even though config says `headless: false`.
- **GitHub OAuth requires env vars** — `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` must be set. Without them, the auth handler is never registered and `/auth/github/login` returns 404. Server logs `"GitHub OAuth disabled"` vs `"GitHub OAuth enabled"` to indicate state.
- **OAuth callback URL**: `http://localhost:8080/auth/github/callback`
