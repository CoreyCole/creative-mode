## Learnings

1. **sqlc column overrides for same-package types**: Do NOT include `import` in the `go_type` object when the type is in the same output package. sqlc will generate a self-import (`import "creative-mode/harness/internal/db/sqlc"` inside package `sqlc`) which won't compile.

2. **`GetSwarmSpanTreeRow` fields remain `string`**: sqlc doesn't apply column overrides to result columns of computed/JOIN queries. The `SpanType` and `Status` fields on `GetSwarmSpanTreeRow` stay `string`, so the templ helper functions (`spanIcon`, `spanStatusBadge`, etc.) keep `string` parameters.

3. **Bug found and fixed**: `workflows.go:429` passed `"code_change_plan"` as artifact type to `PersistArtifact`, but the DB CHECK constraint only allows `research_doc` and `plan_doc`. The typed enum caught this — changed to `sqlc.ArtifactTypePlanDoc`.

4. **`exhaustive` linter**: Adding a typed string enum to a switch requires a `default` case or covering all values. Added `default` to the `AgentEventName` switch in `agent.go`.

5. **Boundary pattern for template types**: Functions like `CreateWorld` and `Builder.Build` accept `templateType string` from user input. Casts to `sqlc.TemplateType` happen at the DB call sites, not the function signatures, since these are input boundaries.
