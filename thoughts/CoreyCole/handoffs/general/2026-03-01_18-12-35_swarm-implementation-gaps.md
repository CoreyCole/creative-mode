## Learnings

- **sqlc type generation**: When a SELECT query's column list changes (e.g., adding `revision_target`), sqlc generates a new `ListXxxRow` struct instead of reusing the model struct. This required updating `WorkflowDetailData.GateReviews` from `[]sqlc.SwarmGateReview` to `[]sqlc.ListSwarmGateReviewsByWorkflowRow`.
- **Deny patterns**: The project `.claude/settings.json` denies `templ generate` and `just generate` directly, but `sqlc generate` works. The Stop hook runs `check.sh` which handles all generation + linting.
- **templ auto-regen**: On VPS, air hot-reload automatically regenerates `_templ.go` files when `.templ` files change.
- **Lint requirements**: `gosec` requires WriteFile permissions <= 0600. `mnd` (magic number detector) flags numeric literals in arguments. Unused `//nolint` directives are flagged by `nolintlint`.
- **Datastar radio buttons**: Use `data-bind:signal_name` on radio inputs to bind to a signal. The signal value matches the `value` attribute of the selected radio.
