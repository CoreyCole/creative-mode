## Learnings

1. **golangci-lint v2 `--fix` is powerful** - It auto-fixed nlreturn (79), gofumpt (8), perfsprint (2), usestdlibvars (1), errorlint (2) = 92 issues automatically. Always run `--fix` first.

2. **noctx requires context.Context on ALL DB methods** - The `noctx` linter requires `ExecContext`/`QueryContext`/`QueryRowContext` instead of `Exec`/`Query`/`QueryRow`. This means every DB method signature needs `ctx context.Context` as first param, and every caller must pass it. This is the most invasive change.

3. **errcheck on `defer x.Close()`** - The pattern is `defer func() { _ = x.Close() }()` to explicitly discard the error.

4. **tagliatelle for external API JSON tags** - GitHub API uses snake_case (`avatar_url`, `access_token`). Use `//nolint:tagliatelle // GitHub API format` on the struct field.

5. **gosec G301 (dir perms)** - Change `0o755` to `0o750` or add nolint. G304 (file inclusion via variable) and G204 (subprocess with variable) are best handled with `//nolint:gosec` since they're internal paths/commands.

6. **govet shadow exclusion rule might not work** - The exclusion in `.golangci.yml` for govet shadow on `err`/`ctx` didn't suppress the warnings. The 4 shadow issues were fixed by renaming variables (e.g., `upsertErr`, `countErr`, `buildErr`, `cleanErr`).

7. **forcetypeassert** - Rather than adding `ok` checks everywhere, extract a helper: `requireUser(c echo.Context) (*db.User, error)` that does the checked assertion once.

8. **staticcheck SA1019** - `middleware.Logger()` is deprecated. Replace with `middleware.RequestLoggerWithConfig(...)`.

9. **mnd (magic numbers)** - Extract to named constants (e.g., `oauthStateBytes = 16`, `sessionTTLDays = 7`). For event bus channel sizes and port ranges, extract constants in the respective files.
